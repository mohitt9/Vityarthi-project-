TRIGONOMETRIC CALCULATOR (PYTHON)

A simple terminal-based Python calculator that computes the six basic trigonometric functions. It accepts input in degrees or radians and runs continuously until the user closes the program.

FEATURES
- Supports degrees and radians
- Calculates: sin, cos, tan, cosec, sec, cot
- Menu-driven terminal interface
- Uses Python's built-in math module

REQUIREMENTS
- Python 3.x
- No external libraries required

HOW TO RUN (TERMINAL)

1. Open Command Prompt or Terminal

2. Navigate to the project folder:
   cd Downloads

   Or if the file is inside another folder:
   cd Downloads\YourFolderName

3. Run the program:
   python "trigo calculator.py"

   If that doesn't work:
   py "trigo calculator.py"

EXAMPLE
Welcome to Trigo Calculator

Please enter value:
30

Is your value in radians? y/n
n

What you want to find?
1 -> sin
2 -> cos
3 -> tan

Enter: 1

Output: 0.5
